# P4剧场 · P4 Theater

作品、现场、公共档案与研究的阅读入口。  
An index of works, live practice, public archives and research.

P4剧场是始于北京的独立实验剧场与创作共同体。何发与张绍华于2015年前后共同发起P4，此后何发长期主理并组织创作。表演、摄影、影像和写作在这里形成具体项目，也留下参与者的文字、图像与历史记录。

## 作品与项目 · Works and projects

### 《人类投降派》 / Shoot Self with You

2023–2024年的实验电影，从招募、排练、拍摄与公开演出展开。何发担任导演、发起、制片与剪辑；全剧组共同创作。

Directed, initiated, produced and edited by He Fa; collectively created with the full crew.

[官方电影页与观看](https://p4theater.cn/shoot-self-with-you/) · [完整作品资料与署名](https://hefa.p4theater.cn/work/human-surrender) · [项目过程](https://p.p4theater.cn/human-surrender/)

### 《膜下》 / Under the Membrane

与《人类投降派》相连的互动数字作品。本仓库网络中的 `p4-submembrane-cn` 保存中国域名版本的页面、交互资源与镜像脚本。

[进入作品](https://s.p4theater.cn/) · [国际版](https://s.p4theater.top/) · [GitHub仓库](https://github.com/hehefa/p4-submembrane-cn)

### 从项目原文继续

[《实像》系列](https://p.p4theater.cn/series/shixiang/) · [《最后的排练》](https://p.p4theater.cn/last-rehearsal/) · [AGT方法](https://p.p4theater.cn/agt/) · [按年份阅读文章](https://p.p4theater.cn/articles/)
